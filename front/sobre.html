Sobre o projeto

O Sistema de Biblioteca foi desenvolvido como projeto acadêmico utilizando HTML, CSS e JavaScript.

O objetivo é facilitar o cadastro, consulta, alteração e exclusão de livros.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • LocalStorage
  • Git
  • GitHub
